博客推倒了，重做。

旧的站点换过很多次皮肤：终端风、玻璃拟态、侧边栏、杂志风……每一次都以为"这次对了"，过一阵子又觉得不对劲。后来想明白了——我真正需要的不是一个好看的外壳，而是一个能安安静静写字的地方。

所以这次重做，做减法：

- **Astro** 构建，纯静态，打开就是文字
- 没有乱七八糟的小部件，结构清晰就够了
- 排版优先：合适的行高、舒适的栏宽

```python
def restart():
    return "千里之行，始于足下（又一次）。"
```
